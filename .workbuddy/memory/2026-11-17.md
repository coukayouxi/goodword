## 单词美好器（GoodWord）
- 应用户要求做成标准 Vite + Vue3 工程（明确"不要单文件"），组件化结构：
  - `index.html`（Vite 入口）/ `vite.config.js` / `package.json`（vue ^3.4.38, vite ^5.4, @vitejs/plugin-vue）
  - `src/data/words.js`：A–Z 26 美好词表（Astra/Bliss/…）+ 随机示例词
  - `src/composables/useBeautifier.js`：核心逻辑（字母映射、空格分隔、词首大写、复制降级方案）
  - `src/components/`：WordInput（输入+随机/清空）、ResultPanel（美好句+复制）、LetterTile（字母卡片，交错入场动画）、AlphabetLegend（A→Z 词表，点击追加字母）
  - `src/App.vue` + `src/assets/main.css`：柔和紫粉渐变、光斑浮动背景、毛玻璃卡片
- `npm run build` 验证通过（22 模块，gzip JS 28.6KB）；`npm run dev` 跑在 5173 端口
- 运行方式：`npm run dev`（开发）或 `npm run build` + `npm run preview`
